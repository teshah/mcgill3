# McGill Big 3 Isometric Interval Timer

A clean, responsive, mobile-optimized interval timer tailored for the **McGill Big 3** core endurance protocol (Curl-Up, Side Bridge, Bird Dog).

## Workout Protocol
- **1 Rep**: 10-second hold + 3-second rest
- **1 Set**: 6 repetitions
- **Set Rest**: 45 seconds rest between sets
- **Sets**: 3 sets default (customizable)

## Key Features
- **Mobile First & PWA Ready**: Optimized for iPhone & Android browsers with full-screen standalone support.
- **Screen Wake Lock**: Automatically prevents the phone display from dimming or sleeping during holds.
- **Audio & Voice Coaching**: High-contrast visual cues, Web Audio synthesizer countdown beeps (3-2-1), and voice announcements ("Hold", "Rest", "Set Complete").
- **Offline Capable**: Zero heavy external dependencies, runs smoothly anywhere.

## How to Install as an iPhone App (1-Click)
1. Open `https://teshah.github.io/mcgill3/` in **Safari**.
2. Tap the **Share** button (📤).
3. Tap **Add to Home Screen**.
4. Tap **Add** in the top right corner.
