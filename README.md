# McGill Big 3 Isometric Interval Timer

A clean, responsive, mobile-optimized interval timer tailored for the **McGill Big 3** core endurance protocol (Curl-Up, Side Bridge, Bird Dog) developed by Dr. Stuart McGill and demonstrated by Dr. Brandt Peterson.

## 🛡️ Workout Protocol & Features
- **6 - 4 - 2 Descending Pyramid**: Set 1 (6 reps) → Set 2 (4 reps) → Set 3 (2 reps) to build postural endurance without fatigue-induced form breakdown.
- **10-Second Holds with Micro-Rests**: 10s isometric holds separated by 3s rests to prevent muscle hypoxia and allow tissue re-oxygenation.
- **Sequential Blocks Full Routine**: Autonomously guides through:
  1. **Curl-Up Block** (6-4-2)
  2. **Side Bridge Block** (6-4-2 on Left & Right sides)
  3. **Bird Dog Block** (6-4-2 with 3s sweep)
- **Form Video Links**: Direct timestamp links to Dr. Peterson's video demonstrations for each movement.
- **Peer-Reviewed Science & DOIs**: Integrated modal explaining NIRS oxygenation, spinal load limits, and direct DOI citations for Dr. McGill's landmark papers.
- **Mobile First & PWA Ready**: Optimized for iPhone & Android browsers with full-screen standalone support and Screen Wake Lock API (prevents display dimming mid-workout).
